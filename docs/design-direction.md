# 前端美化计划 · 视觉方向建议

体检日期：2026-10-25。扫描对象：`output/playwright/frontend-examples/`（index.html 305 KB、gallery.css 25 KB、gallery.js 9.7 KB、86 张截图、86 条案例数据）。

---

## 一句话结论

这个项目已经站在正确的方向上（暖纸底 + 墨绿 + 目录式侧栏 + 平铺卡片），**不要再换一套风格，而要把"纸本图录"这条线做绝**：壳层退到近无彩，靠网格、编号、字号和细线组织信息，把全部颜色让给 86 张截图。

配方一句话：**Stripe Press 的版式 + Pentagram 的索引 + Monocle 的刊头 + Vercel 的壳 + Linear 的交互手感。**

理由很硬：这个站点 90% 的视觉内容是别人做的截图，风格是它的**内容**，不是它的**外壳**。外壳一旦有材质、渐变、动效，就会和截图互相污染——同一张 Linear 截图在玻璃拟态页面里会显得脏，这不是网站的问题，是壳的问题。

## 体检：现在是什么样

读 `gallery.css` 得到的实际值：

| 项 | 现状 |
| --- | --- |
| 底色 / 纸面 / 墨 / 次 / 线 | `#f6f5f1` / `#fff` / `#202822` / `#67716b` / `#dde2da` |
| 强调色 | `--green:#244f3b`（近黑墨绿）；元素模式另起一套 `--element:#8c5327`（棕） |
| 字体 | 正文 `system-ui` 中文黑体栈，14px/1.65；衬线只出现在自绘示意里 |
| 骨架 | 页头（刊头+统计+覆盖折叠）→ 250px 常驻吸顶侧栏 → 主区（说明卡 + 工具栏 + 3 列卡片） |
| 断点 | 1400px 降两列、800px 侧栏塌成单列、540px 单列；1100px 起自绘示意换行 |
| 卡片 | `aspect-ratio:1.44` + `object-fit:contain`、1px 边框、8px 圆角、白底、17px 内边距 |
| 状态 | 筛选写入 URL hash、支持前进后退；**无键盘操作、无暗色、无密度切换、无对比** |

已经做对的四件事（别改）：

1. 暖纸底而不是纯白——86 张截图里深色站很多，暖白让它们"挂在墙上"而不是"贴在屏幕上"。
2. 卡片是"图 + 说明"而不是"图 + 按钮"——这是图录而不是商品列表，方向对。
3. 两套筛选维度（风格 / 元素）用并列而非嵌套，交叉筛选的价值保住了。
4. 用 1px 细线而不是阴影分隔——克制，继续。

拖后腿的三处：

1. **首屏 chrome 过重**：页头 + 统计 + 覆盖折叠 + 侧栏 + 说明卡 + 工具栏，六层都在第一屏，卡片要滚一下才看到。图录的第一屏应该直接是"墙"。
2. **强调色用散了**：绿同时用于 eyebrow、统计数字、标签、选中态、焦点框；再叠上元素模式的棕，一段页面里有三种"状态色"在被解读，截图自己的颜色反而退到背景。
3. **截图框 `object-fit:contain` + `aspect-ratio:1.44`**：原图 1440×1000（1.44）恰好相等，所以目前勉强没露灰边；一旦换成 16:10 或竖屏截图，两侧就会露 `#e7eae4` 灰条，看起来像缺图。`elements-preview.jpg` 里已经有两张卡片显示为空灰块（`loading="lazy"` 在截图时未触发），同一症状。

## 推荐主方向：纸本图录 / 博物馆索引

一句话定义：**把站点做成一本可筛选的图录（catalogue），不是做成一个产品官网。**

它决定了四件事：

- 视觉层级按"刊头 → 栏目 → 图版 → 图注"排，不按"hero → 卖点 → CTA"排。
- 每张卡片是"图版 + 图注"，编号（01–86）是导航资源，不是装饰。
- 颜色只有两处：内容（截图）和一个状态色；其余全靠灰阶、字重、留白。
- 动效只用于"回应操作"（hover、选中、切换），不用于叙事。

## 明确不抄的（很关键）

这四类在你库里都有，但它们是**内容**，不是**壳**：

| 不抄 | 为什么 |
| --- | --- |
| 玻璃拟态（55/56/71）、液态玻璃（71/72） | 背景需要色彩与图像去折射，会直接改变截图的观感 |
| 新拟态（57/58）、黏土（73） | 阴影方向与光源假设会和截图里的光影冲突 |
| 3D 沉浸（06/59）、大字滚动叙事（04/08） | 首屏被占、滚动劫持，图录最不需要"被带着走" |
| 新粗野主义（42）、像素（51）、终端（53/54） | 强个性皮肤会把 86 个案例压成同一种味道 |

## 落地 token（可直接替换 `gallery.css` 的 `:root`）

```css
:root{
  --bg:#f7f6f2;          /* 纸：比现在 +1 明度，减少与 #fff 卡片的跳变 */
  --paper:#fffdf9;       /* 图版纸 */
  --ink:#171a17;         /* 墨：压深，正文更清楚 */
  --muted:#5f6760;       /* 图注 */
  --line:#e2e0d8;        /* 细线：略暖，避免发绿 */
  --accent:#1f4a38;      /* 唯一状态色（选中/焦点） */
  --element:#8c5327;     /* 元素模式专用，只保留这一个第二色 */
  --radius:3px;          /* 8px → 3px，图录不需要胶囊 */
}
```

字体（只加两个文件，中文仍走系统字）：

```css
--font-display: "Inter Tight", "Noto Serif SC", serif;   /* 刊头、栏目名、卡片标题 */
--font-mono: "JetBrains Mono", ui-monospace, Consolas;   /* 编号、URL、计数 */
```

字号阶梯（现在 20px 卡片标题与 14px 正文之间是断的）：

| 用途 | 值 |
| --- | --- |
| 刊头 h1 | `clamp(40px, 5vw, 72px)`，字距 `-.045em`，行高 1.05 |
| 栏目 / 视图标题 h2 | 22–26px |
| 卡片标题 h3 | 17px（等宽编号 11px 在前） |
| 正文 / 图注 | 14px / 12px |
| meta、URL、计数 | 11px 等宽，`tabular-nums` 右对齐数字 |

## 版式与卡片规范

- 网格：12 列，gutter 24px，外边距 `clamp(20px, 4vw, 72px)`，最大宽 1600px（现在是 1760px，行太长）。
- 卡片列数：≥1440 三列、900–1439 两列、<900 一列（现在是 1400 起降两列，太早）。
- 图版：固定 `aspect-ratio: 16/10`，`object-fit: cover`，`object-position: top left`——**统一裁掉截图底部，永远不露灰边**；首屏 6 张给 `loading="eager"`，其余 lazy。
- 图注：编号（等宽）· 类型 · 用途 一行；名称一行；URL 一行（等宽、可复制）；风格标签一行；观察点两行封顶（`line-clamp:2`），详情折进 `details`。
- 侧栏：220px，`top:0` 吸顶，分组标题 11px 大写字距 `.08em`，条目 12px；移动端收进底部抽屉。
- 页头：高度压到 96–120px，统计数字下沉到工具条右侧（图录的"版权页"位置），把第一屏让给卡片。

## 交互（这个工具真正缺的）

1. **对比托盘**：卡片 hover 出现"加入对比"，最多 3 例并排显示（图 + 关键标签），这是选型时唯一真要做的事。落点 `gallery.js`，不改卡片结构。
2. **键盘**：`↑↓/jk` 在卡间移动、`Enter` 开原图、`Esc` 清筛选、`/` 聚焦搜索、`⌘K` 打开命令面板。
3. **密度两档**：紧凑 6 列 2 行 vs 舒适 3 列；存 `localStorage`，默认舒适。
4. **空状态**：0 结果时显示"当前组合无样本"，并给 2 个相邻可点分类（抄 11-resend 的写法）。
5. **暗色**：只做一个"夜间图录"档（墨底 + 纸色文字），截图给 1px 浅描边防止深色站融进背景；不做跟随系统之外的自动切换。

## 落地顺序（按性价比）

1. 换 `:root` token + 圆角 8→3 + 线色变暖（改 6 行，立刻从"后台面板"变"图录"）。
2. 图版 `cover` + 首屏 eager（修掉灰边/空块症状）。
3. 字号阶梯 + 卡片图注重排（编号前置、观察点两行封顶）。
4. 页头瘦身 + 统计下沉（第一屏直接出墙）。
5. 对比托盘 + 键盘（要动 `gallery.js`，估 150–200 行）。

前 4 步只改 `gallery.css`，不动 305 KB 的 `index.html`；第 5 步才碰脚本。`gallery.js` 目前只有 9.7 KB、单层结构，加键盘和托盘不需要重构。

## 实施记录：Bauhaus 版（2026-10-25）

参考对象 https://dev.remember.style/bauhaus 是私有 Next.js 部署（Cloudflare + OpenNext），页面上没有源码仓库、许可证或作者链接，GitHub 上也搜不到对应仓库；它靠 "Get It" 卖 AI 提示词，不是开源项目。所以这里**没有复制它的任何代码、文案或图片**，只按它公开写出的设计规则（三原色、三形状、几何无衬线、非对称网格、结构诚实、WCAG 22 对比度）重写了一套自己的样式。

改了三个文件：

| 文件 | 改动 |
| --- | --- |
| `output/playwright/frontend-examples/gallery-bauhaus.css` | 新增，19 KB 主题层。`.grid/.card` 的网格线、侧栏选中态、工具条控件、图注、元素小样全部重绘；只改外观，不碰 DOM 与 JS |
| `index.html` | ① head 增加 Google Fonts（Jost / Inter / JetBrains Mono / Noto Sans SC）与主题层引用；② body 开头插入 `<nav class="site-nav">`；③ h1 拆成两行 `<span class="hero-line">`，并加三个纯形状 `<div class="hero-shapes">` |
| `preview-bauhaus/` | 新增四张改版截图（刊头、图版网格、窄屏、元素小样），用来对比 |

关键实现选择：

- **网格线靠卡片自身 2px 描边画**（`box-shadow: 0 0 0 2px`），容器不铺墨色底。原因：筛选后只剩 1–2 张时，铺底的容器会把空出来的格子画成一大块黑，实测截图可见。
- **字重 800/900 的中文标题用 Noto Sans SC**，西文用 Jost；等宽编号、URL、计数用 JetBrains Mono。中文没有字体自带的上下留白，标题行高低于 1.02 会让两行字形叠住。
- **白字只出现在蓝底**（导航选中、元素选中项）；红、黄只做块与标记，不承载 13px 以下的小字，保证对比度。
- **元素小样统一灰度化**（`filter: grayscale(.94)`），只对"讲颜色"的五块（中性色、强调色、撞色、渐变、玻璃）保留颜色，避免 37 种绿与三原色打架。
- **吸顶导航 + 锚点让位**：`scroll-margin-top: 74px`，否则跳"全部案例"时第一行卡会被导航盖住。

回退方式：删掉 `index.html` 里 `gallery-bauhaus.css` 那一行 `<link>` 即可恢复旧版外观（`gallery.css` 与 `style-lab.css` 未被改写）。
